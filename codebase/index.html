VLearn AI Glossary Agent Workflow

File này chỉ mô tả cách agent hoạt động khi học viên prompt VLearn AI về glossary trong lúc học một slide/video. Đây không phải UI cuối cùng và không phải chatbox prototype.

Visual agent flow

Student VLearn AI Agent AI Decision Answer shown in VLearn AI
Start Student is stuck on terms While watching the lesson, the student asks VLearn AI:
Tạo glossary cho slide này
asks
Retrieve Agent reads lesson context Current slide/video/topic, transcript if available, and related chat history from the same topic.
checks
Decide Grounding + confidence Does each keyword have source evidence? Is the term ambiguous? Is the answer safe to show?
routes
Response Glossary answer Definition, source, related keywords, and suggested learning order appear inside VLearn AI.
↓

After the decision step, the agent chooses one of four response routes below.

A Happy path Return grounded glossary, related terms, and learning order.
B Low confidence Give limited answer and ask learner to verify.
C No grounding Refuse to invent; say there is not enough lesson evidence.
D Correction Record learner feedback and mark result for checking.
↓
Final Response inside VLearn AI The answer stays scoped to the current lesson and does not judge the student's ability.

End-to-end workflow

Input 1. Student prompts VLearn AI Ví dụ: Tạo glossary cho slide này, Giải thích attention, Backpropagation là gì trong bài này?
↓
Context retrieval 2. Agent lấy context bài học hiện tại Agent đọc slide/video/topic hiện tại, transcript nếu có, và lịch sử hỏi đáp liên quan đến cùng topic.
↓
AI decision point 3. Agent kiểm tra grounding và confidence Agent quyết định thuật ngữ có căn cứ trong bài không, có đủ nguồn để định nghĩa không, và có bị mơ hồ nhiều nghĩa không.
↓
Happy path Đủ căn cứ Trả glossary gồm định nghĩa ngắn, ví dụ theo bài, nguồn slide/trang, keyword liên quan, và thứ tự học đề xuất.
Low confidence Có căn cứ yếu hoặc thuật ngữ mơ hồ Trả câu trả lời giới hạn, gắn nhãn độ tin cậy thấp, và đề nghị học viên kiểm tra với tutor/giảng viên.
No grounding Không tìm thấy trong bài Không tự bịa định nghĩa. Agent nói chưa đủ căn cứ trong bài học hiện tại và gợi ý hỏi tutor.
Correction User sửa/góp ý Nếu học viên nói định nghĩa chưa rõ/sai ngữ cảnh, agent ghi nhận góp ý và đề xuất bản sửa có kiểm chứng.
↓
Final output 4. Agent trả kết quả trong VLearn AI Output không đánh giá học viên yếu hay giỏi. Output chỉ hỗ trợ tra cứu thuật ngữ trong bài và giải thích mối liên hệ giữa keyword.

Example output contract

Field Ví dụ Mục đích
term Embedding Keyword quan trọng trong bài.
definition Vector số biểu diễn token để model xử lý. Giải thích ngắn, đúng ngữ cảnh bài.
source Slide 12: "Each token is mapped into an embedding." Cho học viên biết căn cứ.
related_terms token, attention Thể hiện mối liên hệ giữa glossary/keyword.
learning_order token → embedding → attention Đề xuất thứ tự tìm hiểu.
confidence high / low / no-grounding Quyết định agent tự trả lời hay thu hẹp phạm vi.

Safety logic

Situation Agent behavior
Keyword có trong bài và nguồn rõ Trả lời trực tiếp, kèm nguồn và mối liên hệ.
Keyword có nhiều nghĩa Chỉ giải thích theo ngữ cảnh bài học, không định nghĩa chung chung.
Keyword không có trong bài Không bịa. Báo chưa đủ căn cứ và đề nghị hỏi tutor/giảng viên.
User muốn sửa kết quả Ghi nhận correction, không âm thầm thay đổi nếu chưa kiểm chứng.
