From tokens to attention

A sentence is split into tokens. Each token is mapped to an embedding, then the model uses attention to compare context across the sequence.

Attention(Q, K, V) = softmax(QKT / √d) V

Students often ask about the difference between token, embedding, attention, and loss in the same topic. This prototype turns those repeated questions into a guided glossary.
